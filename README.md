davIA PDF Maker
​O davIA PDF Maker é uma ferramenta desenvolvida para facilitar a criação de arquivos PDF de forma prática e rápida.
​✨ Funcionalidades Principais
​Criação Ágil de PDFs: Gere documentos de forma simples a partir do seu código Python.
​Interface Fluida: Projetado para rodar sem complicações, focado na experiência do usuário.
​Pronto para Uso: Empacotado em um único arquivo executável (.exe) para facilitar a distribuição e execução em diferentes máquinas Windows sem necessidade de instalar o Python.
​🚀 Como Utilizar
​1. Baixe / Acesse o executável do projeto.
​2. Execute o arquivo para iniciar a aplicação.
​3. Siga as instruções ou utilize as funcionalidades conforme o seu objetivo.
​🛠️ Tecnologias Utilizadas
​Python: Linguagem de programação principal.
​PyInstaller / Auto-py-to-exe: Ferramentas utilizadas para converter o script Python em um executável independente.
